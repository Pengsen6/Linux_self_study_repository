## 一、Linux基础命令
**1. ls** （list）列出文件夹中内容
后可加 -a -l -t -r -h，分别对应all, long, time, 递归, human
也可以组合使用，如 -al， -a -l（与前者等价，显示所有信息的长版
-althr 或 -al -h -r 混合使用，很自由

**2.cd** (change directory) 切换当前目录
可分为绝对路径和相对路径
*(1) 绝对路径* Linux中只存在一个根文件，用 "/" 来表示，以此为出发点到当前文件的路径为绝对路径
*(2) 相对路径* 以当前文件夹到目的文件夹所经过的路径为相对路径，特别的, /Home/kelilus 可用 "~" 来进行表示，直接进行cd指令也会回到个人用户的当前目录
如 cd test1
     cd /Home/kelilus/桌面 都是可以的
补充: 在进行目录切换时，若加 "." 代表当前所在的目录自身，".."表示目录的上一级父目录，但在根目录下执行".."不会跳出根目录

**3.mkdir** (make directory) 创建文件目录
同样可分为**绝对路径**和**相对路径**创建文件目录
不同的是在创建但目录时，可以直接创建mkdir dirname
但在创建多层目录时，需加上 -p 来自动补全不存在的父目录，也就能达到一次创建一连串目录的结果 mkdir -p name1/name2/name3/name4 (p代表parents)

**4.touch**  创建单文件
可以一次性创造多个文件, 如 touch test1.txt test2.txt
touch ../dirname1/test.txt 回到上一层的一个文件夹中创造txt文档

**5.cp** (copy) 复制文件
cp在复制普通文件时可以直接进行复制，如cp test1 test2（相当于复制一份test1命名为test2到当前目录下），同时copy对象和被copy对象也可以根据相应的绝对路径和相对路径来决定复制哪里的文件到哪
如果要对文件夹进行复制，要在cp 后加上-r，因为要复制的是一整个文件夹的内容，要进行递归来遍历该文件夹内的所有文件，就算文件夹里没有文件，这也是必要的。

**6.mv** (move) 移动文件
将某个文件/文件夹移动到另一个文件夹里面，后者对象不能为非directory对象
如 mv test.txt test2.txt 是不允许的  合法的为：mv text/dir1 dir2

**7.rm** (remove) 删除文件
基础用法 rm test1/dir 若要删除文件夹，则应像cp一样在前面加上-r进行递归遍历
补充: *name 检查所有后缀是该名字的；name* 前缀是该名字的; *name* 含有该名字的
结合rm *test 可批量删除名字结尾为 test 的文件，对于mv也是可用的
注意：sudo rm -rf /* 极其危险

**8.more**  翻页读文件内容
more text1.txt 可以按空格和下来读文件的内容

**9.cat** 一次性输出文件所有内容，不提供翻页阅读

**10.pwd** (print work directory) 输出当前工作目录

**11.poweroff/shutdown**  关机，前者立刻关机，后者会计划在一个时间关机

**12.reboot**  重启

**13.whoami**  查看自己是谁
目前只学习到命令的基础，如mv, rm还可与-f, -r等进行结合来特化使用
