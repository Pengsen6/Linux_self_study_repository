## 一、Linux基础命令
**14.which**  查找所使用的一系列命令的程序文件存放在哪里
which 要查找的命令
如 which cd ; which pwd

**15.find** 按文件名查找文件
find 起始路径 -name "被查找文件名"
-type: f表示文件 d表示目录 ; -size按大小查找 +100M表示查找大于100MB的文件
如 find -size +100M; +表示大于，-表示小于
-mtime 按修改时间
-exec 对查找到的文件执行指定的命令
同样可以通过通配符*前置后置来一键搜索所有带该名字的文件或目录

**16.grep** 从文件中通过关键字过滤文件行
grep [-n] 关键字 文件路径， 关键字最好用双引号""括起来
找到该文件中含所给关键字的那一行并给出

**17.wc** 统计文件行数，单词数量等
wc [-c  统计bytes数量，-m 统计字符数量， -l 统计行数， -w 统计单词数量]

**18. |** 管道符， 将管道符左边命令的结果作为右边命令的输入
如 ls | grep "name" ，从前面列出的文件找出含"name"的列出来

统计文件中带有itcast关键字的有几行: grep -n "itcast" test | wc -l （test为文件名
也可以 cat test | grep itcast | wc -l
统计文件中带有abc关键字的结果中有多少单词: grep -n "abc" test | wc -w

**19.echo** 用于在终端输出文本
echo 要输出的文本
-n不在输出末尾添加换行符

**20. 反引号** ``
被反引号包裹的内容会被视作命令而非普通字符

**21.重定向符>和>>**
**>** 将左侧命令结果覆写到右侧指定文件中
**>>** 将左侧命令结果追加写入右侧指定文件中
输入输出不能为同一文件

**22.tail**查看文件尾部内容
tail -f -num 路径
-f 表示持续跟踪 ，也就是改动文件时，终端会显示出新的结果
-num 表示查看尾部多少行，不填默认10行

**23.head**查看文件头部内容
与tail类似，不再赘述

输出任意内容并追加到文件中
echo Linux >> test.txt
