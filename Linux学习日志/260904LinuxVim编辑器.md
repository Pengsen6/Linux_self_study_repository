# Linux学习日志 26.09.04
## Vim编辑器
vim 文件名称  进入命令模式
输入i a o进入输入模式 Esc返回命令模式
**i.** 光标当前位置进入输入模式
**a.**光标当前位置之后
**I.** 光标当前行开头
**A.** 光标当前行结尾
**o.** 当前行下一行
**O.**当前行上一行
输入**:冒号** 进入底线命令模式 回车返回运行
输入w q 保存并退出

**命令模式**
$移动光标到当前行结尾，0移动光标到当前行开头
n向下继续搜索，N向上继续搜索，按下/进入搜索模式
dd删除光标所在行内容, ndd删除光标向下n行
yy复制当前行，nyy复制当前行和向下n行
p粘贴复制的内容
u撤销修改
ctrl+r 反向撤销修改
gg跳到首行
dG从当前行开始，向下全部删除
dgg从当前行开始，向上全部删除
d$从当前光标开始删到本行结尾
d0从当前光标开始删到本行开头

**底线命令模式**
:wq 保存并退出
:q 仅退出
:q! 强制退出
:w 仅保存
:set nu显示行号
:set paste设置粘贴模式
